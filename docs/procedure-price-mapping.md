# Procedure-price mapping

Mapping precedence is exact approved code, exact reviewed alias, exact normalized description, source-specific reviewed mapping, then manual review. Draft code mappings and similarity candidates cannot publish. CPT, HCPCS, DRG, revenue, ICD-10-PCS, local, and unknown source codes are retained.

A mapped line item is not a complete episode unless a separately reviewed bundle and source explicitly establish that scope. Review candidates in the admin pricing queue, confirm the code and setting, and approve through audited database workflow before rebuilding summaries.
