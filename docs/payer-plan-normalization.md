# Payer and plan normalization

Source payer and plan strings are always preserved. Normalization changes only case, punctuation, whitespace, and reviewed common suffixes. Exact canonical names and active deterministic aliases may map automatically. Similar names alone never merge distinct products; ambiguous or unknown values remain unresolved.

To add an alias, review representative source rows, associate it with the canonical payer or plan, record source provenance and confidence, then activate it. Plan approval must retain its payer, product, network, and plan-type distinctions for future Transparency in Coverage reconciliation.
